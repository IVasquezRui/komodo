# Especificación Técnica Mobile `8.1#`: CTA Flotante y Selector de Cantidad de Asientos en USD

> **Proyecto:** Komodo Mobile (`React Native + Expo SDK ~57.0.8`, puerto `8081`)  
> **Requerimiento:** `8.1#` — Transición entre Vista de Detalles del Viaje (`app/trip-details.tsx`) y Selección 2D de Asientos (`app/select-seat.tsx`).

---

## 1. Flujo de Navegación y Estado

1. **`app/search-results.tsx` → `app/trip-details.tsx`:**
   El usuario selecciona una salida en `TripCard` y navega a Detalles del Viaje con:
   - `tripId`, `operator`, `busModel`, `origin`, `destination`, `dep`, `arr`, `unitPriceUsdCents`, `availableSeats`, `routeCode`, `hasWifi`, `hasAc`.
2. **CTA Flotante (`FloatingPurchaseCTA`):**
   Anclado en la zona inferior sobre `SafeAreaInsets.bottom`, mostrando `"Seleccionar asientos"` y el precio base unitario formateado desde centavos enteros (`formatUsdFromCents(unitPriceUsdCents)`). El `ScrollView` superior aplica `paddingBottom >= 120 + insets.bottom` para evitar obstrucción.
3. **Panel Selector (`SeatQuantitySheet`):**
   Modal inferior interactivo con controles `-` / `+` acotados estrictamente entre `1` y `min(6, availableSeats)`. Calcula el total en tiempo real mediante `calculateTotalUsdCents(unitPriceUsdCents, quantity)` en **centavos enteros** (sin aritmética de punto flotante).
4. **Validación Online / Offline-First al Confirmar (`"Continuar"`):**
   - Consulta conectividad con `@react-native-community/netinfo` (`NetInfo.fetch()`).
   - **Si está Offline:** Muestra aviso no destructivo dentro del panel explicando que el bloqueo distribuido de asientos en Redis (`POST /api/v1/hold-seat`) requiere conexión activa y permite presionar `"Reintentar"` preservando exactamente la cantidad seleccionada.
   - **Si está Online:** Prepara `draftBookingId` + `idempotencyKey` (UUID v4 generado en cliente) y navega a `/select-seat` enviando:
     - `tripId`, `seatQuantity`, `unitPriceUsdCents`, `estimatedTotalUsdCents`, `draftBookingId`, `idempotencyKey`, `operator`.

---

## 2. Contratos de Componentes y Utilidades (`TypeScript Estricto`)

### `mobile/lib/pricing.ts`
- `calculateTotalUsdCents(unitPriceUsdCents: number, quantity: number): number`
- `formatUsdFromCents(cents: number): string` → `"$35.00 USD"`
- `clampSeatQuantity(requested: number, availableSeats: number, maxPerBooking?: number): SeatQuantityBounds`
- `validateConnectivityAndBuildParams(input): SeatSelectionNavParams`

### `FloatingPurchaseCTA` (`mobile/components/FloatingPurchaseCTA.tsx`)
| Prop | Tipo | Descripción |
|---|---|---|
| `unitPriceUsdCents` | `number` | Tarifa unitaria en centavos enteros USD |
| `availableSeats` | `number` | Cupos disponibles en el bus |
| `onPress` | `() => void` | Abre `SeatQuantitySheet` |
| `ctaLabel?` | `string` | Por defecto `"Seleccionar asientos"` |

### `SeatQuantitySheet` (`mobile/components/SeatQuantitySheet.tsx`)
| Prop | Tipo | Descripción |
|---|---|---|
| `visible` | `boolean` | Controla apertura del panel |
| `tripId` | `string` | UUID del viaje |
| `operatorName` | `string` | Nombre de operadora |
| `unitPriceUsdCents` | `number` | Precio por asiento en centavos |
| `availableSeats` | `number` | Cupos disponibles |
| `maxSeatsPerBooking?` | `number` | Límite de negocio (default `6`) |
| `onClose` | `() => void` | Cierra el panel |
| `onConfirm` | `(params: SeatSelectionNavParams) => void` | Navega a `select-seat` |
